# Vasile Groza · O poezie pe zi

Oglinda site-ului memorial [vasilegroza.ro](https://vasilegroza.ro): opera poetului Vasile Groza (1937–2025), 1.968 de poezii în 12 cărți.

- Site-ul întreg, static (HTML, CSS, JS), se deschide și de aici: https://andreuxb.github.io/vasilegroza/
- `corpus/`: textele, ca fișiere deschise (JSON), ca să poată fi citite și peste 50 de ani: `carti.json`, `poezii/<carte>.json`, `fire.json`, `teatru/`.
- `media/descarca/`: fiecare carte în PDF (de tipărit) și EPUB (pentru cititoare).

Drepturile asupra textelor aparțin familiei. Site-ul original: https://vasilegroza.ro
